#### Local development

```bash
# clone this repo
git clone https://github.com/danielesteban/sdf-video.git
cd sdf-video
# install dependencies
pnpm install
# start the dev environment:
pnpm start
# open http://localhost:8080/ in your browser
# press the spacebar to jump to the next slide.
```
